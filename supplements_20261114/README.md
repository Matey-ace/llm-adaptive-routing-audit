In particular, third-party benchmark questions, model outputs, dependencies and other third-party materials retain their respective source conditions. ESM_2 is the original historical archive prepared for an earlier manuscript version; its internal title, repository address and hold status describe that earlier snapshot. This directory supplies it unchanged as evidence for the revised manuscript and does not assert that the snapshot describes the current submission status. Reproduction instructions and data provenance inside each archive retain their original scope and limitations.
